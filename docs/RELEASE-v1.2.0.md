# AstroDay v1.2.0

## What's new

- The desktop image placement selector now fully follows the selected theme.
- Library selections are easier to identify with a thicker accent border and drop shadow.
- When today's APOD is not a still image, AstroDay checks up to five earlier days before keeping the current desktop wallpaper.
- A Windows installer is included. Choose an install folder and optionally enable Windows sign-in startup, desktop shortcuts, and launch minimized to the system tray.
- The installed version is shown prominently in the window title bar.
- Update details include links to the repository and release, plus a direct installer download when an update is available.

## Windows installer

Download `AstroDay-Setup-v1.2.0.exe` for a guided per-user installation. The installer never requires moving the portable application manually.

## Portable build

`AstroDay-win-x64.zip` remains available for users who prefer not to install AstroDay. Extract the complete archive and keep all included support files beside `AstroDay.exe`.
