# AstroDay v1.3.0

## What's new

- AstroDay starts in a normal window after installation by default.
- Added a matching AstroDay orbit/planet icon for the executable, installer, Start menu, and desktop shortcuts.
- The installer lets you choose where downloaded images and `library.json` are stored.
- Upgrades detect the installed version, stop the running app, and replace application files in place.
- Image libraries and their catalogues are excluded from uninstall content. Changing folders preserves the old library and backs up conflicting destination files.
- The installer preselects an existing library path during upgrades.

## Installation

Download `AstroDay-Setup-v1.3.0.exe` for the guided per-user installer. Choose the installation directory, image-library directory, startup behavior, and launch-at-finish behavior.

## Portable build

`AstroDay-win-x64.zip` remains available for users who prefer not to install AstroDay. Extract the complete archive and keep all included support files beside `AstroDay.exe`.
